# 아뜰 ATT:L 웹 이력서

Instagram `@attl.growthinking` 프로필 링크에서 연결해 사용할 것을 기준으로 만든
브랜드형 웹 이력서입니다.

## 특징

- 첫 화면에서 '아뜰' 브랜드와 교육 철학을 먼저 노출
- 부모교육 / AI·디지털 교육을 하나의 브랜드 아래 연결
- 강의 가능한 주제를 별도 섹션으로 구성
- 이소영 강사의 경력과 역량은 브랜드 신뢰를 뒷받침하는 구조로 배치
- Instagram 링크와 이메일 문의 버튼 포함
- 2026년 7월 비공개 경력은 포함하지 않음
- 모바일 반응형 구성

## GitHub Pages 배포

1. ZIP을 풉니다.
2. 안의 파일 전체를 GitHub Repository 최상위에 업로드합니다.
3. Repository → Settings → Pages
4. Source: `Deploy from a branch`
5. Branch: `main`, Folder: `/ (root)`
6. 저장하면 GitHub Pages 주소가 생성됩니다.

## Instagram 연결

Instagram `@attl.growthinking` 프로필의 링크 영역에
GitHub Pages 주소를 넣으면 됩니다.
